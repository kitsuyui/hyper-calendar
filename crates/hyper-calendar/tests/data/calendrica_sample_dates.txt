# What this file is, and how it was changed from the source (section 4(b)).
# dates.l does not hold the tables: it lists the 33 dates, as R.D. -214193
# to 764652 written as Hebrew, Julian and Gregorian dates, names the
# calendars in seven lists, and writes the tables out as TeX by running
# calendar.l. This file is that program's output in plain text instead of
# TeX: every date of dates.l's `dates` converted by the `<name>-from-fixed`
# function of every name in its lists `calendars-1` to `calendars-7`, one
# line per date and name, with the fields in the order of calendar.l's
# constructors. The values were produced on 2026-09-27 by
# scripts/calendrica-sample-dates.py, a Common Lisp subset interpreter
# written for the purpose because no Lisp system was at hand; every
# conversion outside dates.l's `do-not-invert-list` was checked to convert
# back to its R.D., as dates.l's own `convert` checks. Moments are printed
# in full; dates.l prints six decimals. The book's printed appendix was not
# read.
#
# Checked against: the third edition's tables written by the same program,
# dates1.tex to dates4.tex as distributed with pycalcal
# (https://github.com/espinielli/pycalcal, read 2026-09-27, under the third
# edition's own licence, so nothing of them is copied here). They agree with
# this file in all but one of the 4 290 values of the 39 date columns the
# two editions share: astro-bahai at R.D. 25469, whose function the fourth
# edition changed, from the third's future-bahai judged at Haifa's sunset
# to Tehran's. The one moment column they share,
# major-solar-term-on-or-after, differs by up to 9.1 minutes, as the fourth
# edition's new ephemeris correction would make it.
#
# Which of these columns this library carries, under what identifier and
# with what differences, is crates/hyper-calendar/tests/rd_sample_dates.rs;
# the Accuracy sections of the system documents under docs/systems say what
# it showed for each calendar. Where the code's output differs from what
# its own errata state (reingold2018errata, corrections 14 and 15), this
# file keeps the code's output and the test says so.
#
# Format: "<name> TAB <R.D.> TAB <fields>", fields separated by spaces, "t"
# and "f" for true and false; a comment line before each name gives its
# fields.
