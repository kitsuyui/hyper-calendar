# Month lengths of the Japanese lunisolar calendar, 862-1844.
#
# One line per lunisolar year:
#
#     <fixed day of 1/1>  <ordinal of the leap month, 0 if none>  <lengths>
#
# <lengths> has one character per month in order, 'L' for a 30-day month and
# 'S' for a 29-day one, with the leap month in its place; so a line with a
# non-zero leap ordinal has thirteen characters and every other line has
# twelve.  The fixed day is a Rata Die: Rd(1) is 0001-01-01 proleptic
# Gregorian.
#
# Provenance: the 西暦との対照表 published in the Japanese Wikipedia article
# for each 元号, which tabulates the Julian and Gregorian date of the first
# day of every month and marks the 29-day months.  Those tables are derived
# from 内田正男『日本暦日原典』 (雄山閣, 1975), the standard reconstruction
# of the Japanese calendar.  The 242 era tables covering 862-1844 were
# harvested, de-duplicated across the Northern and Southern Court overlap,
# and cross-checked three ways before being written here:
#
#   * every one of the 12145 intervals between consecutive month starts is
#     exactly 29 or 30 days;
#   * the tables' own 小の月 marks agree with those measured intervals in
#     every case;
#   * the Julian and the Gregorian columns, which the tables give
#     independently, agree with each other in all 3959 rows that carry both.
#
# This is a single source family, and it is Wikipedia's transcription of
# Uchida rather than Uchida himself.  A separate scrape of 2096 dated events
# from unrelated Japanese Wikipedia articles agrees with it on 96.9% of
# cases, the disagreements being scattered single-article errors.
